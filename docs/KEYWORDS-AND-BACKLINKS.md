## Submission candidates

These are candidate platforms, not confirmed listings, verified submission forms or guaranteed backlinks. Account ownership, eligibility, prices and link attributes must be checked on each platform before submitting. Prefer updating an existing profile over making a duplicate.

| Candidate | Useful action | Prerequisite |
| --- | --- | --- |
| [LinkedIn](https://www.linkedin.com/) | Add or update the official company page with the description and website | Authorized company account; check for an existing page |
| [Clutch](https://clutch.co/) | Consider a service-provider profile for custom software and web/app development | Verify eligibility and current terms; use genuine project evidence and reviews |
| [GoodFirms](https://www.goodfirms.co/) | Consider a software-development/service profile | Verify relevant category, terms and real business details |
| [Google Business Profile](https://www.google.com/business/) | Add or update an eligible real-world business profile | Business must meet Google's customer-contact/location rules; online-only businesses are generally ineligible |
| [Bing Places](https://www.bingplaces.com/) | Consider an eligible business listing | Verify current availability, category and location requirements |
| Actual clients and integration partners | Request a contextual link in a real project write-up or partner directory | Existing relationship, permission and accurate project claims |
| Relevant UAE business associations | Request an official member-directory entry | Actual membership; check current directory rules |

Profile links may be nofollow or otherwise qualified. They can help discovery and consistent identity without necessarily passing ranking credit. Paid placements must follow the publisher's disclosure and link-qualification rules. Avoid bulk backlink sellers, comment spam, reciprocal-link schemes and fabricated reviews.
